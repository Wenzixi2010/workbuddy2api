# WorkBuddy2API 1.14.0

本次正式版新增「单独同步客户端参数」功能，修复 DeepSeek Harness 提示词触发的 11128 渠道校验拦截，并修复模型检测与测速相关的若干问题。

## 更新内容

- **新增单独同步客户端参数**。客户端参数页面新增「同步客户端参数」按钮，只把当前生效的 UA / 版本号 / 风控头推送到线上实例，不连带账号与模型配置。远程 URL 与密钥沿用「线上同步设置」里已保存的配置，推送前弹出确认，结果提示同步字段数量与错误原因。后端 `POST /api/sync/push` 新增 `only_client_profile` 参数，为真时账号与模型列表置空，接收端按原有逻辑自动跳过，因此线上实例无需升级即可正确接收。
- **修复 DSH 提示词触发的 11128**。上游对 DeepSeek Harness 的 @ 路径说明段做的是标记词共现判定：单句各自放行，`Tokens prefixed with @ ...` 与 `Relative paths resolve from the workspace root` 一旦同现即返回 400 code=11128，截断到第 111 字符仍稳定复现；把其中任一句同义改写即恢复 200。现按同义改写打散该段的标记词，保留原意，挂在不受脱敏开关影响的全量模板归一流程上。
- **模型检测改为选择账号**。检测弹窗从「选择 API Key」改为「选择账号」，列出启用中的账号（名称、ID、剩余积分），默认仍为公共账号池自动选号。后端检速接口新增 `account_id`，指定后直接使用该账号发起检测，`key_id` 保留兼容。
- **修复指定 Key 检测必定 500**。账号池选号在指定 Key 分支引用了不存在的 `db` 变量，导致 `NameError` 并使接口返回 500，现改为使用查询对象自带的会话，并修正单列查询的取值方式。
- **修复测速非 JSON 响应报错与下拉框显示不全**。测速接口返回非 JSON 时前端解析抛出 `Unexpected token 'I', "Internal S"...`，现改为容错解析并回落到 HTTP 状态码提示；检测弹窗的账号选择改为弹窗内固定高度可滚动列表，与模型分组的模型选择一致，能显示多少显示多少，其余滚动查看。
- **修复测速提示中的标签被显示成文本**。提示条使用纯文本渲染，原先手写的 `<b>` 标签会原样显示，现改为纯文本提示。
- **更新检测仓库地址**。全部更新检查与公告链接从 `xiaofan6ya/workbuddy2api` 改为 `Wenzixi2010/workbuddy2api`，README 补充原仓库已删除的说明。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `WorkBuddy2API-1.14.0-windows-x64.exe` |
| Android ARM64（Android 7.0 及以上） | `WorkBuddy2API-1.14.0-android-arm64.apk` |

Windows 使用新版 EXE 更新；Android 使用同签名 APK 覆盖安装，保留账号与配置。两端均提供 `.sha256` 校验文件，旧版本可通过客户端更新检查发现本次正式版。

## 验证范围

- 已在本机与线上实例分别回放真实的 `POST /v1/messages` 请求（携带完整 DSH 前言与工具定义），修复前稳定返回 503 且上游为 400 code=11128，修复后返回 200；中性提示词在修复前后均为 200，确认差异来自提示词内容而非设备令牌。
- 单独同步客户端参数已实测：推送到线上实例后返回 `applied: true`、`source: saved`，账号与模型新增/更新均为 0，线上实例读回的桌面端版本、CLI 版本、UA、操作系统、架构与风控渠道号均与本地一致。
- 模型检测按账号选取已实测：指定账号检测成功返回首字延迟、补全 token 数与速率；指定 Key 检测不再出现 500。
- 本版本未重新构建 Windows / Android 安装包，上表文件名对应后续构建产物。
